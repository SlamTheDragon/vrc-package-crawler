# Source access checkpoint (2026-09-27)

This is an engineering gate record, not legal advice. Driver selection is distinct from authorization to issue live requests or retain/publish fetched material. The new node defaults to all seven capabilities but receives no jobs until the local operator explicitly seeds them. Only the isolated, metadata-only VPM and GitHub smoke runs described below have been performed; no sustained source crawl has run.

| Driver | Current evidence | Live-access conclusion for this iteration | Remaining work |
| --- | --- | --- | --- |
| Jinxxy | [Jinxxy Terms §23](https://jinxxy.com/terms-of-service) says automated access uses its official API absent written permission | Do not start DOM scraping without confirmed API authorization or written permission | Obtain and document permission/API scope, rate and retention terms; replace the DOM adapter accordingly |
| Gumroad | [Gumroad Terms §14(e)](https://gumroad.com/terms) restrict automated scraping, with a revocable public-search-index exception that excludes caches/archives | Do not assume the local prototype qualifies for that exception | Review project qualification and exact retained representations; get legal review before live archival/history |
| BOOTH | Not yet reviewed to a source-specific access/retention profile | Unresolved | Primary terms, robots paths, image/description retention, rate and challenge behavior |
| Itch.io | [Itch.io Terms](https://itch.io/docs/legal/terms) reviewed at a high level only | Unresolved | Review exact automated access/robots and API options, retention and publication |
| GitHub | [Get a repository](https://docs.github.com/en/rest/repos/repos#get-a-repository) permits unauthenticated reads of public resources; [REST rate limits](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) specify 60 unauthenticated requests/hour per IP and authoritative rate headers. [API terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#h-api-terms) and [acceptable-use policy](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies#7-information-usage-restrictions) still govern downstream use. The new node uses only `GET /repos/{owner}/{repo}` metadata, pins API version 2026-03-10, stores bounded description/link/date evidence, and requires a 60-second local origin delay plus reset-header backoff. An opt-in compiled smoke fetched `vrc-get/vrc-get` once and persisted its repository ID and bounded metadata in a temporary DB | Narrow one-off public repository metadata test passed; no HTML scrape, API search, README/content archival, or automated portfolio harvest is approved by this review | Validate attribution/privacy and publication policy, shared-IP budget across deployments, primary/secondary rate-limit integration and sustained-run limits before broad ingestion |
| VPM | Repository manifests are distributed across many hosts; there is no single platform-wide permission. A one-off metadata-only smoke fetched VRChat Community's published example listing and raw template recipe on 2026-09-27; no ZIP was requested. Its GitHub Pages host returned no `robots.txt` (HTTP 404). | Per-origin review required for further sources or sustained crawling | Validate authoritative manifest format, host robots/terms, version evidence, and repository links; the successful example fetch is not a blanket permission grant |
| Curated | A lead may point to a different origin and does not carry its authorization | Per-origin review required | Source provenance, link relation types, host policy, and no automatic promotion of copied claims |

This matrix deliberately does not label every selected driver “permitted.” The local protocol and fixture tests may advance while source-specific decisions are pending. The standalone node's [pinned HTTPS metadata transport](NODE_FETCH_SAFETY.md) blocks obvious private-network egress and redirects, but is not an access license. A first live-development run should record the approved endpoint list, request policy, retention/publication rule, and stop condition for each platform or origin before seeding its jobs.
