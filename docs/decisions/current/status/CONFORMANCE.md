This records reproducible implementation evidence separately from the future-facing covenants in root `LEGAL.md` and the work order in [`docs/decisions/plans/IMPLEMENTATION_PLAN.md`](../../plans/IMPLEMENTATION_PLAN.md). **Structure-migration checkpoint (2026-09-28):** After the owner's move into `src-crawler/`, repaired imports, package smoke commands and migration-sensitive test paths pass `bun run typecheck`, compiled node/coordinator builds, Worker browser-target bundles, `smoke:local` and `smoke:multi` from that package. This is a path/layout checkpoint, **not** a completed two-binary/two-config/two-database topology or a final post-production architecture specification. The separate top-level `node/` and `worker/` code boundaries, test location, Linux builds, and flaky-suite cause remain open.
